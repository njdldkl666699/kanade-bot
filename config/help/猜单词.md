# 猜单词

## Wordle

修改自插件`nonebot-plugin-wordle`。

### `/wordle [长度] [词典]`

别名：`/猜单词`

参数：

- `长度`：单词长度，默认为5
- `词典`：指定词典，默认为`CET4`

开始一局Wordle猜单词游戏。一个会话中只能进行一局游戏。

如果配置了水晶奖励，则猜出单词后会获得水晶奖励，奖励数量根据单词长度而定。

### `/词典`

别名：`/wordle_dictionaries` `/猜单词词典` `/词典列表`

列出所有支持的词典。

### `/提示`

别名：`/wordle_hint` `/猜单词提示`

获取这局猜单词的提示。

### `/结束`

别名：`/wordle_stop` `/结束游戏` `/结束猜单词`

结束当前会话的猜单词游戏。

## 猜成语

修改自插件`nonebot-plugin-handle`。

### 规则

你有十次的机会猜一个四字词语；

每次猜测后，汉字与拼音的颜色将会标识其与正确答案的区别；

汉字的右上角标的数字1、2、3、4分别对应一、二、三、四声；

青色 表示其出现在答案中且在正确的位置；

橙色 表示其出现在答案中但不在正确的位置，至多着色 **此单词中有这个字母的数量** 次；

每个格子的 汉字、声母、韵母、声调 都会独立进行颜色的指示。

当四个格子都为青色时，你便赢得了游戏！

使用`handle.strict_mode`选项开启成语检查，即猜测的短语必须是成语。

### 说明

橙色块着色规则为：

```
橙色块至多着色 此成语中有这个元素的数量 次。
```

同时其满足：

```
橙色块着色数量 + 青色块着色数量 <= 此成语中有这个元素的数量。
```

类似Wordle，这意味着：

**如果答案是 `zu2 bu4 chu1 hu4`。**

玩家猜测 `hu1 xx1 xx1 xx1`(x代表无关)，则

`h` 标为橙色。

`1` 声在第 3 格标记青色，其他为灰色。（因为着青色的数量达到最大值 1）

玩家猜测 `hu4 hu4 su4 su4`，则

第 1 个 `h` 着橙色，第 2 个 `h` 着灰色。（因为着青色的数量达到最大值 1）

`4` 声在第 2、4 格着青色，在第 1、3 格着灰色。（因为着青色的数量达到最大值 2）

四个 `u` 全部标记为青色。

#### 特殊标记

若所猜拼音下，出现双下划线，则代表该声母/韵母是出自同一个出现在答案中的字。

## Mindle 猜配方

猜 Minecraft 工作台合成配方。开始游戏后发送可合成物品的精确中文名称，每次猜错会展示该物品的 3×3 合成表：

- 绿色：原料种类和位置都正确
- 黄色：原料种类正确，但位置错误
- 红色：原料种类错误

没有放置原料的格子视为“空气”；猜测和答案的同一位置均为空气时，该格为绿色。

与猜单词、猜成语不同，猜配方游戏中，必须使用`/猜 <物品名称>`命令进行猜测，而非直接发送物品名称。

> 猜配方功能所用的物品图片资源、配方数据均归 Mojang Studios 所有，禁止用于商业用途。

### `/mindle`

别名：`/开始猜配方`

开始一局猜配方游戏。默认有 10 次机会，一个会话中只能进行一局猜配方游戏。

如果配置了水晶奖励，猜出配方后会获得对应数量的水晶。

### `/猜配方 <物品名称>`

别名：`/mindle_guess` `/猜`

发送可合成物品的精确中文名称进行猜测。

如果发送的名称匹配多个物品，则会列出至多 10 个相近物品，且不消耗尝试次数。

### `/mindle_hint`

别名：`/提示` `/猜配方提示`

随机提示正确配方中尚未提示过的一种原料，并显示其中文名、物品 ID 和图片。所有原料都提示过后，再次使用会随机重复已有提示。

### `/mindle_stop`

别名：`/结束` `/结束猜配方`

结束当前会话的猜配方游戏并公布答案。

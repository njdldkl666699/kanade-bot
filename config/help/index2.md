# 总结

### `/总结 <消息条数>`

别名：`/summarize` `/summary`

参数：`消息条数`必填，要总结的消息数量，必须为正整数。

总结最近的消息内容，返回总结结果。Bot会尝试总结最近指定数量的消息内容，并返回一个总结。请注意，Bot的总结能力可能会受到消息内容的复杂程度和数量的影响，因此总结结果可能不完全准确或详尽。

# 语音合成

### `/tts [语言id] <文本>`

参数：`语言id`可选，指定语音合成的语言。缺省为`auto`自动检测。支持：`auto`、`auto_yue`、`en`、`zh`、`ja`、`yue`、`ko`、`all_zh`、`all_ja`、`all_yue`、`all_ko`

将文本合成为角色语音发送。

# 命令统计

### `/命令排行 [时间段]`

别名：`/top_commands` `/查看命令排行`

参数：`[时间段]`可选，默认为今天。包括：

- `昨天` `昨日`
- `本周` `这周`
- `本月`
- 数字，表示过去的天数，包含今天。例如`/命令排行 7`表示过去7天的命令排行。
- 其他参数值均解析为今天。

查看指定时间段内的命令使用排行，按使用次数从高到低排序，显示前10条命令。

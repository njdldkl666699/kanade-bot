# v6.4.0 功能更新日志

## ✨ 新功能

### 表情包全面升级：Bot 会自己挑表情

- **语义匹配取代点名**：Bot 使用表情包时不再需要预知库里有什么，只需按想要的效果表达（如"开心到手舞足蹈"），系统会自动匹配最贴切的一张；匹配不到时宁缺毋滥，不会乱发表情
- `/添加表情 [补充标签…]`（超级管理员）：回复（引用）一张图片发送此命令即可收录，Bot 会用视觉模型自动打中文语义标签，命令后可追加补充标签；自动打标失败时会先以待打标状态收录，稍后可用 `/改标` 补标
- `/改标 <序号> <标签…>`（超级管理员）：更新指定表情的语义标签，空格分隔多个标签
- `/删除表情 <序号>`（超级管理员）：删除指定表情，同步删除图片与索引记录
- `/扫描表情`（超级管理员）：扫描表情包目录，把手动放入但未收录的图片自动打标入库，并清理文件已被手动删除的悬空记录
- `/表情包列表`：现在显示每条表情的序号、文件名与语义标签，序号供上述命令引用

### 聊天

- **QQ（OneBot v11）私聊支持**：现在私聊也可以和宵崎奏聊天了，私聊消息需以 `宵崎奏` 开头
- **真 @**：Bot 回复中 @ 某人时是真正的 @ 消息段，会被 QQ 正常高亮和提醒
- **时间感知**：Bot 现在能看到每条消息的发送时间，隔夜的"早上好"不会再被当成刚刚说的

### 会话管理命令开放私聊

- `/重置会话`、`/中断会话`、`/压缩会话`、`/清理工作区` 在私聊中任何人可用（群聊中仍需超级管理员权限）

## 🔧 优化与调整

- 定时任务到点提醒不再默认 @ 创建者，改由 Bot 根据任务内容自行决定提醒谁
- 聊天记录总结中每条消息现在附带发送时间，时间线更清晰
- 帮助文档重新分组（会话 / 定时任务 / 黑名单 / 表情包），命令索引同步更新

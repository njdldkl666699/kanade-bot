# v6.6.0 更新日志

## ✨ 新功能

### 视频链接自动解析

- 发送支持平台的视频链接、BV号或小程序卡片，Bot 会自动解析并发出视频，支持：B站、抖音、快手、微博、小红书、YouTube、TikTok、Twitter、AcFun、NGA
- `bm BV号 [分集]`：提取 B站视频的音频
- `ym 链接`：提取 YouTube 视频的音频
- `blogin`：扫码登录 B站账号，可解锁需要登录的清晰度（可选）

### 聊天

- **图片发送更自然**：Bot 直接在回复文字中用 Markdown 图片语法发图，不再调用单独的发图工具。图片既可独立成行单独发送，也可夹在文字中间按原始顺序合并进同一条消息；地址支持网络链接和工作区内的文件
- **新增文件下载能力**：Bot 拿到直链后可以流式下载到自己的工作区（单文件上限 2GiB），配合文件发送即可实现"先下载再转发"
- **看图更省**：Bot 查看图片默认看压缩图，需要细节时才看原图

### 主动回复增强

- **互动后更容易接话**：被 @ 或被动回复过一次后，Bot 会把当前话题纳入决策历史，并重置该会话的防抖与退避——被动互动说明话题在场，后续群消息大概率相关
- **活跃群不再"明明热闹却沉默"**：待判定消息量每达到阈值的整数倍，就额外尝试一次主动回复决策，概率未抽中则继续累积到 2 倍、3 倍再试
- 决策通过但最终未发出回复（如消息已被被动回复消费）时，会如实补记，Bot 不会误以为自己已经说过话

## 🔧 优化与调整

- 回复中引用表情包与 @ 某人时，消息段按原始位置插入，与前后文字的顺序不再错乱
- 主动回复的决策上下文增加长度护栏：估算 token 超出决策模型窗口比例时自动截断，保留最近的完整判定轮

## ⚠️ 升级注意事项

- **配置项改名**：`config.yaml` 中 `chat.auto_reply:` 段更名为 `chat.proactive:`；`config/chat/chat_configs.json` 中的启用群键改为 `proactive_enabled_groups`，旧键**不会自动迁移**，存量文件需手动改名
- **命令别名更新**：`/启用主动回复` `/禁用主动回复` 的英文别名改为 `/proactive_enable` `/proactiveenable`、`/proactive_disable` `/proactivedisable`（旧 `auto_reply` 系列别名失效）
- Agent 的 `send_image` 工具移除，发图统一改用回复中的 Markdown 图片语法

## 🔨 技术性变更

- 主动回复术语统一：代码 / 配置 / 文档中的 `auto_reply` 全量更名为 `proactive`，设计文档更名为 `PROACTIVE_DESIGN.md`
- 用户输入重构：废弃 `$` 前缀分隔拼接，RAG 检索片段、消息缓冲、引用消息、系统通知、时间行等各来源独立成段，作为同一轮输入的多个文本部分随图片一起发送；旧格式历史天然兼容
- OneBot v11 适配层补充两个获取文件下载链接的接口封装
- 会话查看器（session_viewer）兼容分段式用户消息的展示

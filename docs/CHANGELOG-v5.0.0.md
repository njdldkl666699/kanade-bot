# 更新日志

## 全新玩法

### Mindle：猜 Minecraft 合成配方

新增 Minecraft 工作台配方竞猜玩法：

- 使用 `/mindle` 或 `/开始猜配方`开始游戏，默认拥有 10 次机会。
- 使用 `/猜 <物品名称>`提交答案；名称不准确时会推荐相近物品，且不会消耗次数。
- 每次猜测都会展示 3×3 合成表：
  - 绿色：原料与位置均正确
  - 黄色：原料正确，但位置错误
  - 红色：原料错误
- `/提示`可查看尚未提示过的配方原料，包括中文名、物品 ID 和图片。
- `/结束`可提前结束游戏并公布答案。
- 猜中后可获得配置的水晶奖励。

### 猜成语

新增基于 Wordle 规则的四字成语竞猜：

- 使用 `/猜成语`开始游戏，共有 10 次机会。
- 直接发送四字词语即可猜测。
- 汉字、声母、韵母和声调会分别标色，帮助逐步推断答案。
- 支持严格成语检查，避免无效四字词语参与游戏。
- 支持 `/提示`和`/结束`，猜中后可获得水晶奖励。
- 游戏长时间无人操作时会自动结束并公布结果。

### 群聊决斗

新增西部牛仔式群聊决斗：

- 使用 `/决斗 @用户`发起挑战，对方发送 `/同意`接受。
- Bot 会在随机等待后喊出“开始”，随后最先发送 `/开枪`的玩家获胜。
- 提前开枪会被判定为抢跑，并直接落败。
- 对方长时间未接受、开始后双方均未开枪时，决斗会自动结束。
- 每个群聊同一时间只能进行一场决斗。

## 聊天与消息体验

### 图片理解能力优化

启用图片转述功能后，Bot 会先通过专用视觉模型提取图片中的场景、人物、文字、布局等信息，再交给聊天模型处理，使看图问答和图片上下文理解更加完整。

图片转述模型现在可以独立配置模型、服务商、推理强度、提示词及可用工具，并增强了现实人物、二次元角色和画面文字的识别指引。

### 新增消息撤回命令

超级管理员现在可以引用一条消息并发送 `/撤回`、`/撤回消息`或 `/recall`，让 Bot 尝试撤回该消息。

该功能适用于 OneBot v11；消息已撤回、超过撤回时限或 Bot 权限不足时，会返回明确提示。

## 配置与部署改进

- 新增 YAML 配置方式，可通过 `config.yaml`与 `config-{环境}.yaml`拆分公共配置和环境专属配置。
- 环境配置支持深度合并，敏感信息可以单独存放在不会提交到仓库的环境文件中。
- 原有 `.env`与 `.env.{环境}`配置仍然兼容，可以与 YAML 共存。
- 提供完整示例配置及合并后的 Schema，在支持 YAML Schema 的编辑器中可获得字段提示和自动补全。
- Watchdog、聊天模型、图片转述及新增游戏的配置已统一接入新配置体系。
- 重构 Wordle 模块结构，使猜单词、猜成语和猜配方能够共用会话与命令规则，同时保持原有 Wordle 使用方式不变。
- 帮助文档已同步补充所有新增命令和玩法说明。
